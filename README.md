his is a basic Python script that functions as a command-line calculator. It accepts user input in the form of a simple arithmetic expression (e.g., 4 + 5) and returns the result after evaluating the expression.

Features:

Supports basic arithmetic operations:

Addition (+)

Subtraction (-)

Multiplication (*)

Division (/)

Input validation and error handling for:

Incorrect formatting

Division by zero

Invalid operators
Note:
Only space-separated input is accepted (e.g., 4 + 5, not 4+5).
